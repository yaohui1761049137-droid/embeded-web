# 07: 前端 change.html + 入口 + 预警横幅

- Type: task
- Status: open
- Blocked by: 04, 06

## 任务

1. 新建 `www/change.html`:自改密表单(当前密码/新密码/确认新密码),客户端先用 JS 做策略预检(长度 10-64、四类各一、拒绝中文/空格,与后端规则一致,仅 UX 提示),提交到 `user_change_pass.cgi`;成功提示后跳转 main.cgi。
2. `control_panel.html`:导航/页头加"修改密码"入口(打开 change.html);任意请求返回"密码已过期,请先修改密码"时自动跳转 change.html。
3. 7 天预警:登录后主控页展示"密码将于 X 天后到期"横幅(不阻断)。数据来源建议:login.cgi 在会话表/响应中带出,或新增轻量状态接口(实现时选最简单者;后端返回 JSON 时可在现有字段中带 `days_left`)。

## 验证

- 浏览器手工走通:到期登录 → 强制进 change.html → 改密成功 → 回主控页功能恢复;
- 未到期用户控制面板有"修改密码"入口;
- 剩余 ≤7 天用户登录后可见预警横幅。
